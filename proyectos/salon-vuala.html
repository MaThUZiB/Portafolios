Salón Vualá

Reservas y administración

Desarrollo de una aplicación web para gestionar reservas de horas y centralizar operaciones de un salón. Un proyecto orientado a simplificar la administración diaria del negocio.

Ver código ↗

El problema

La gestión de reservas de un salón necesita centralizar las horas y la información del negocio para facilitar la organización diaria.

Mi participación

Desarrollo de una aplicación web con Django orientada a la reserva de horas y la administración del salón.

Funciones principales

  • Gestión de reservas de horas.
  • Organización de servicios y disponibilidad.
  • Centralización de operaciones administrativas.

Tecnologías principales

Python · Django · Tailwind · Railway
