Auditorías de producción apícola

Participación en el desarrollo de un sistema de auditorías con Laravel para evaluar apiarios y colmenas. Gestión de información y reportes para apoyar la evaluación de buenas prácticas apícolas.

Ver sitio ↗

El problema

Las evaluaciones de buenas prácticas apícolas necesitan organizar criterios, registrar información y comunicar resultados de forma clara.

Mi participación

Participación como desarrollador full stack Laravel en un equipo de trabajo, contribuyendo al sistema de auditorías para producción apícola.

Funciones principales

  • Evaluación de apiarios y colmenas bajo criterios de buenas prácticas.
  • Gestión de información para las auditorías.
  • Generación de reportes y trabajo colaborativo.

Tecnologías principales

PHP · Laravel · MySQL · Tailwind · jQuery
